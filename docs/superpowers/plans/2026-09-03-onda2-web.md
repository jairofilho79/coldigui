# Onda 2 — web (ordem única com `kind`, material unificado, estabilidade) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fechar a ordem única de materiais da playlist de ponta a ponta (Isar → wire → Worker → URL), unificar `LouvorGroup`/sheet/abertura sobre `CatalogMaterial`, e corrigir os 13 itens de estabilidade B5–B17 + E9.

**Architecture:** Três subprojetos do spec. A: `PlaylistEntry{id, kind}` vira a fonte de verdade em `SavedPlaylist`, com `itemKinds` no Isar, `items` como objetos no wire v2, coluna `items` no D1 e `shareitems` na URL. B: `LouvorGroup` guarda `sections` + `extras: List<CatalogMaterial>`, um `MaterialSheet` único, porta `CatalogSource` e `resolveCatalogMaterial` ligando os desvios ao `openMaterialProvider`. C: itens S/M independentes (Isar indisponível + lock offline, bulk robusto, race do leitor, deep link, token/Dio/`userMessageFor`, áudio, cifra com cache, catálogo com retry, timeout do Isar + `AppLogger`), e por fim o sync tolerante (B8/B9).

**Tech Stack:** Flutter 3 web (WASM), Riverpod 3, go_router, Isar Plus (síncrono na web; `dart run build_runner build --delete-conflicting-outputs`), Dio, just_audio, `google_sign_in` 7.x; Worker Cloudflare (`workers/plpcg-catalog`, TypeScript, D1, testes `node:test`).

**Spec:** `docs/superpowers/specs/2026-09-03-onda2-web-design.md` (autoridade: `PRODUCT.md` §Product Principles e `docs/USER_AUTH_PLAYLIST_SYNC_SPEC.md` §6–§7). Levantamento com `arquivo:linha` atual em `.superpowers/sdd/2026-09-03-onda2-web/wave2-explore.md` (copiado pelo controlador).

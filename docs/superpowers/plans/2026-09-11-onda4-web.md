# Onda 4 — web (UX de culto, folheto e link curto, performance restante, arquitetura) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fazer do leitor um lugar de culto em tela cheia e tela larga (mini-player persistente, split view, ajuste/fullscreen/spread/última página, cifra com autoscroll e colunas), dar à Home estados vazios úteis e ao card os materiais e o «+» sempre, fechar listas (nome, desfazer, duplicar) e player (±10 s, velocidade, posição), folheto com áudio e link curto com dedupe do import, os itens de performance restantes (A6, A13, A14, A15) e a arquitetura de base (flags, `PlatformCapabilities`, `AppFailure`, splits, `test/support`).

**Architecture:** Cinco subprojetos do spec. A: `MiniPlayerBar` no shell (overlay em fullscreen), `Title` por rota, porta `ReaderFullscreenPlatform`, `ReaderPreferencesDatasource` com última página, `spreadPageLayout`, cifra por família de `chordId` com `SliverList` e memo de transposição, `ReaderSplitLayout` + `ActiveListPanel`. B: `HomeEmptyState` + `recentlyOpenedProvider`, `MaterialKindsRow` + `preferredMaterialForGroup` + `HighlightedText`, `ActivePlaylistNameChip` + `deleteWithUndo` + `DuplicatePlaylist`, `seekBy/setSpeed` + `AudioPlaybackPositionStore`, persistência de filtros e página. C: `GenerateLeafletFromEntries`, `contentFingerprint` no import, Worker `short_links` + `ShareLinkShortener`. D: quota pelo índice, nav memoizada, código morto. E: `FeatureFlags`/`appTabsFor` + `NavigationRail`, `AppFailure`/`failureMessage`, `PlatformCapabilities`, splits dos god files, `test/support`.

**Tech Stack:** Flutter 3 web (WASM), Riverpod 3.3 (`ref.mounted`, `autoDispose`+`keepAlive`, `retry: (_, _) => null`, `NotifierProvider.family`), go_router (`StatefulShellRoute`), Isar Plus (síncrono na web), pdfrx 2.4.4 (`layoutPages`, `getPageRenderingScale`, `maxImageBytesCachedOnMemory`), just_audio (`setSpeed`), SharedPreferences, `package:web`; Worker Cloudflare (`workers/plpcg-catalog`, TypeScript, D1, `node:test`).

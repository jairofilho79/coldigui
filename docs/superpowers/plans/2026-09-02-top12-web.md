## Task 4: Catálogo — só baixar o manifest quando o checksum mudou (A1)

**Arquivos:** `lib/features/catalog/presentation/providers/louvores_manifest_provider.dart`, `lib/features/catalog/data/repositories/catalog_repository_impl.dart`, `lib/features/catalog/data/datasources/catalog_remote_datasource.dart`, `lib/features/catalog/data/datasources/catalog_local_datasource.dart`, `lib/features/catalog/data/datasources/manifest_checksum_store.dart`, `lib/features/catalog/domain/repositories/catalog_repository.dart`, `workers/plpcg-catalog/src/index.ts`, testes em `test/unit/features/catalog/**`, `workers/plpcg-catalog/**` (testes se existirem).

Comportamento hoje (`louvores_manifest_provider.dart:29-36`): com cache, dispara `_refreshFromRemote()` sempre, que baixa o manifest inteiro, refaz `clear()` + ~4600 `put` e emite novo estado.

Comportamento novo:
1. No boot com cache: chamar `/api/catalog/checksum` com `If-None-Match` do checksum salvo (`ManifestChecksumStore`). Se 204/igual → **não** baixar o manifest, não reescrever Isar, não emitir novo estado; apenas atualizar `isStale` se aplicável. Se diferente (ou o endpoint falhar por 503 "checksum not configured") → baixar o manifest como hoje.
2. Ao baixar o manifest, comparar com o cache antes de gravar: se a lista for idêntica (mesmo tamanho e mesmos `pdfId`+`nome`+`numero`+`groupId` em ordem, ou hash do JSON), pular `cacheManifest` e não emitir estado. Reaproveitar o `cached` já em memória em vez de chamar `loadLouvores()` de novo em `_refreshFromRemote`.
3. Worker (`index.ts` `fetchLouvores`): incluir `ETag: "<checksum>"` (lido de `catalog_meta`) na resposta de `/louvores` e responder 304 quando `If-None-Match` bater. O cliente Dart envia `If-None-Match` quando tem checksum salvo e trata 304 como "sem mudança".
4. Falha de rede em qualquer etapa mantém o comportamento cache-first silencioso, com `debugPrint('[catalog] …')`.
Testes: unidade do notifier/repositório com datasource fake: (a) checksum igual → `fetchManifest` não chamado; (b) checksum diferente → manifest baixado e gravado; (c) manifest idêntico ao cache → `cacheManifest` não chamado; (d) 304 → sem gravação.
